## 📂 精选项目

### [Pop！OS护眼 · eyecare-overlay](https://gitee.com/kiopen/pop-os-eye-protection)

> 给 Linux Wayland 桌面加一层「护眼模式」：在 `wlr-layer-shell` 的 overlay 图层上铺一层半透明暖色，压低蓝光、减轻夜间用眼刺激。

- **技术栈**：Rust 85.4% · Shell 14.6%
- **特性**：鼠标点击穿透、不抢焦点、覆盖全部显示器、支持热插拔
- **适用**：COSMIC · Sway · Hyprland · Wayfire 等实现了 `zwlr_layer_shell_v1` 的合成器
- **协议**：MIT
